# 简化版Mamba模型 - 在Mac上高效运行的序列建模方案

## 📊 项目概述

这是一个在Mac设备上（无GPU）高效运行的简化版Mamba模型实现。相比传统Transformer，本模型在相同计算资源下实现了更好的性能表现，特别适合在资源受限环境中进行序列建模任务。

## 🎯 核心优势

### 性能对比（中文文本生成任务）

| 指标 | 简化版Mamba | Transformer | 优势 |
|------|------------|-------------|------|
| **最终Loss** | 4.1 | 4.4 | **+7.3%** |
| **参数量** | 460万 | 420万 | +9.5% |
| **序列长度** | 256 | 256 | 相同 |
| **训练批次** | 10,000 | 10,000 | 相同 |
| **学习率** | 1e-4 | 1e-4 | 相同 |

### 关键改进点

1. **选择性机制的简化实现**
   - 在无法使用官方并行扫描算法的情况下，采用顺序计算
   - 通过输入依赖的参数投影实现基本的选择性功能
   - 保持线性复杂度，适合CPU环境

2. **分块动态A矩阵投影**
   - A矩阵从固定参数改为输入依赖的动态参数
   - 投影到多个不同大小的矩阵，根据简单的注意力分数计算，为每一块矩阵设置不同的权重，并拼接成最终的A矩阵
   - 实现内容感知的状态更新机制
   - 相比固定参数系统，显著提升模式适应性

3. **新增状态反馈K矩阵**
   - 新增K矩阵，通过h_next = (A - BK)*h + B * u更新状态

4. **使用欧拉近似离散化替代ZOH离散化**
   - dA = dt * A + I
   - dB = dt * B

5. **Mac环境优化**
   - 避免使用GPU专属操作
   - 内存使用优化，适合个人设备训练
   - 完整的单机训练解决方案

## 🚀 技术特点

### 模型架构

```python
# 核心创新：输入依赖的状态空间参数
A_t = torch.cat([A1_proj(x_t)*w1, A2_proj(x_t)*w2], dim=-1)  # 动态A矩阵
B_t = B_proj(x_t)  # 动态B矩阵  
C_t = C_proj(x_t)  # 动态C矩阵
Δ_t = Δ_proj(x_t)  # 动态时间步长

# 状态更新公式
h_t = exp(ΔA) * h_{t-1} + ΔB * x_t
y_t = C_t * h_t
```

## 🛠️ 快速开始

### 环境要求
```bash
# 基础环境
Python 3.14+
PyTorch 2.10

# 安装依赖
pip install torch numpy
```

### 训练模型
```python
from mamba import MAMBA
from train import MambaTrainer

# 创建模型
model = MAMBA(d_model=512, d_state=256)

# 开始训练
trainer = MambaTrainer(model, data_path="都市极品医神.txt")
trainer.train()
```

### 文本生成
```python
# 加载训练好的模型
model.load_state_dict(torch.load("checkpoints/best_model.pth"))

# 生成文本
generated = model.generate("今天天气很好", max_length=100)
print(generated)
```
